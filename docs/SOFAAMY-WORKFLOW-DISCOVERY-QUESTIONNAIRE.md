# Sofaamy Workflow Discovery Questionnaire

**Prepared for:** Sofaamy Co. Ltd
**Prepared by:** Veloxa Technology Limited
**Purpose:** Understand Sofaamy's real workflow, tools, documents, approvals, and handoffs before designing the unified business system.

## How to complete this questionnaire

Please answer the questions that apply to your role. Short answers are fine. Where possible, please show us the actual document, spreadsheet, drawing, message, or screen used in the process.

We are not proposing to remove AutoCAD, SmartGlazier, Excel, or any other specialist tool that Sofaamy depends on. We want to understand where each tool fits and how the tools can work together through one connected project record.

Please redact confidential client or pricing information if necessary, but keep the dimensions, calculations, drawing references, document names, and workflow steps visible.

## Final note

The purpose of this questionnaire is not to force every activity into one application. The purpose is to identify:

1. Which tool is best for each task.
2. Which information must move between tools.
3. Which document is authoritative at each stage.
4. Who approves each transition.
5. How the complete job can remain visible and traceable in one system.
